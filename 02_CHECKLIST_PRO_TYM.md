# Vesna Club – TEAM TEST checklist

U každého bodu napište **OK / problém / poznámka**. Klidně testujte „nepořádně“ – cílem je najít chyby a nepraktická místa.

## Přihlášení a role

- [ ] Přihlášení jako pracovník
- [ ] Přihlášení jako správce
- [ ] Přihlášení jako čtenář/reporting
- [ ] Čtenář nevidí klientské karty ani administraci
- [ ] Odhlášení a opětovné přihlášení

## Klienti

- [ ] Vyhledání existujícího fiktivního klienta
- [ ] Založení nového fiktivního klienta
- [ ] Editace klienta
- [ ] Klientská karta je srozumitelná
- [ ] Časová osa / historie odpovídá tomu, co bylo zadáno
- [ ] Filtry historie fungují
- [ ] Součty na klientské kartě dávají smysl

## Výkony

- [ ] Nový individuální výkon
- [ ] Oblast → nabídnou se odpovídající činnosti
- [ ] KA1
- [ ] KA2
- [ ] KA3.1 / KA3.2 / KA3.3
- [ ] Hodinový limit KA3 upozorní, ale nezablokuje záznam
- [ ] Výkon se po uložení objeví v historii klienta

## Skupinové akce

- [ ] Založení jedné skupinové akce
- [ ] Přidání více účastníků
- [ ] Přidání pracovníka/pracovníků
- [ ] Účast se správně propíše ke klientům
- [ ] Nevznikají zbytečné kopie celé akce pro každého účastníka

## Denní zápisy

- [ ] Otevření měsíčního/denního kalendáře
- [ ] Nový denní zápis
- [ ] Dva zápisy ve stejném dni
- [ ] Editace zápisu
- [ ] Je vidět autor a historie změn

## Číselníky – testuje správce

- [ ] Přidání nové testovací položky
- [ ] Přejmenování testovací položky
- [ ] Změna pořadí / nadřazené oblasti, kde je relevantní
- [ ] Deaktivace testovací položky
- [ ] Historický výkon zůstane po změně/deaktivaci čitelný
- [ ] Je srozumitelné, proč použitou historickou položku nelze bez následků smazat

## Pracovníci a oprávnění

- [ ] Seznam pracovníků
- [ ] Role pracovníka
- [ ] Role správce
- [ ] Role čtenáře/reportingu
- [ ] Oprávnění se liší i při přímém otevření URL, ne jen schovanými tlačítky

## Indikátory a výstupy

- [ ] Indikátory se zobrazí
- [ ] Jedna osoba se u unikátního indikátoru nepočítá vícekrát
- [ ] Lze dohledat, z jakých elektronických záznamů číslo vzniklo
- [ ] Filtry kontrolního výpisu fungují
- [ ] CSV export
- [ ] XLSX export

## Souběžná práce

Tento bod zkuste ve dvou různých prohlížečích nebo na dvou počítačích.

- [ ] Dva lidé současně vidí společná testovací data
- [ ] Oba otevřou stejný záznam k editaci
- [ ] První uloží změnu
- [ ] Druhý následně nedokáže změnu prvního tiše přepsat; dostane upozornění na konflikt

## Mobil

- [ ] Přihlášení z telefonu
- [ ] Klientská karta
- [ ] Nový výkon
- [ ] Denní zápis
- [ ] Menu a tlačítka jsou použitelná bez horizontálního „lovu“
